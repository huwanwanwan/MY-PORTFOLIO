# ONE PIECE font

Author: Phantom King Graphics. Downloaded from the author's FontSpace listing:
https://www.fontspace.com/one-piece-font-f16014

The listing identifies the font as Public Domain. The original TTF and archive information are retained here.

The README name uses SVG glyph outlines, so the font renders consistently without needing a font installed on the viewer's device. To regenerate, run `python scripts/build-name-wordmark.py` with `fontTools` installed.
