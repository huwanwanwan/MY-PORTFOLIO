# Reference layout artwork

The banner and About illustration use `pirate-reference-art.png`, generated with the built-in image_gen tool. Layout, Wancor branding, real technology logos, labels, project cards, ropes, icons, and charts are SVG. The original PNG is embedded in SVG viewports; it is not a vector tracing. No generated text or numbers are used.

## Generation prompt

Create an anime illustration asset sheet for a One Piece themed developer GitHub README. This is artwork only, absolutely NO TEXT, NO LETTERS, NO LOGOS, NO UI. Wide landscape 3:2 canvas divided into two seamless horizontal panels. TOP HALF: extremely panoramic ocean pirate scene, a large black straw-hat skull pirate flag on wooden mast at far left, gorgeous deep blue sky and clouds across mostly open empty middle, Thousand Sunny sailing ship at far right beside a lush island, foaming ocean waves along bottom. Center area must remain mostly deep dark blue empty to overlay a real logo later. BOTTOM HALF: Monkey D. Luffy, smiling broadly, red open vest, straw hat, black hair, saluting brim with one hand, detailed recognizable face and costume, waist-up framing. Place him on rightmost 40 percent of this lower panel; left 60 percent mostly plain very dark navy blue with a few soft clouds at lower edge, for overlay paragraph later. High quality crisp hand-drawn cel shaded anime, vivid but tasteful navy #161B2F, slate #384358, crimson #B51A2B and peach #FFA586 accents. Keep all important art inset 3 percent from outer edges. The two halves should have clean straight horizontal separation with no dividing line. The art must resemble polished anime splash art, NOT a website screenshot, NO text.

## Data accuracy

`github-data.json` contains only public GitHub summary data. The daily workflow generates this snapshot and builds the reference layout. Contribution streaks count consecutive days, allowing an unfinished current day; total active days are not labeled as a streak. Achievement cards list completed courses recorded in data/certifications-data.ts. The InventoPOS 100/100 academic milestone is recorded in data/projects-data.ts. No earned GitHub achievement ranks are claimed.
